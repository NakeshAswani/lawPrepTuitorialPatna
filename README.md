# ⚖️ Law Prep Tutorial Patna – Educational Website

A static educational website built using HTML and CSS, designed to present structured course information with a clean and professional layout.

## 🌐 Live Demo
https://law-prep-tuitorial-patna.vercel.app/

## 🧰 Tech Stack
- HTML
- CSS

## ✨ Features
- Clean and structured educational website layout
- Responsive design for desktop and mobile devices
- Well-organized sections (Courses, Faculty, About, Contact)
- Simple and user-friendly interface
- Consistent typography and spacing

## 🧠 Project Overview
This project is a frontend educational website created to practice layout structuring and responsive UI design using pure HTML and CSS. The focus was on building a professional and readable educational platform interface.

## 📥 Installation & Setup
1. Clone the repository  
    ```bash
    git clone https://github.com/NakeshAswani/lawPrepTuitorialPatna.git
    ```
2. Navigate to the project directory
    ```bash
    cd lawPrepTuitorialPatna
    ```
3. Open the project
    ```bash
    Open index.html in your browser
    ```
